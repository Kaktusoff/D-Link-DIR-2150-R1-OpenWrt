## Что входит в образ

Официальная базовая система и LuCI с темой Bootstrap. Список 161 установленного пакета извлечён непосредственно из образа: [packages.json](metadata/packages.json).

**Podkop, Sing-box, Zapret, Adblock, WireGuard и наши последующие настройки не встроены в этот файл.** Их отдельно устанавливали и настраивали на обслуживаемом устройстве. [Заметки по этой конфигурации](CONFIGURATION-NOTES.md) описывают результаты того обслуживания, но не являются автоматическим установщиком или копией готовой конфигурации.

Пользовательские пароли, SSH-ключи, VPN-профили и резервные копии конкретного роутера в публикацию не включены. У чистого образа нет заданного пароля root: задайте свой пароль при первом входе.

## Совместимость и установка

Этот файл предназначен для **обновления уже установленного OpenWrt на ревизии R1**. Он не предназначен для DIR-2150 A1 и не является factory-образом для загрузки через штатный интерфейс D-Link.

1. Проверьте ревизию на наклейке и модель в OpenWrt. Сохраните собственную резервную копию настроек.
2. Скачайте файл и `SHA256SUMS` из релиза. Сверьте SHA256.
3. В LuCI откройте раздел обновления прошивки, выберите файл и проверьте результат проверки совместимости. Не обходите отказ проверки параметром принудительной прошивки.

Метаданные этого образа имеют `compat_version=1.1` и предупреждают о переходе **swconfig → DSA**. Старую сетевую конфигурацию swconfig сохранять нельзя. Если установленная система сообщает несовместимость, сначала разберите переход для её конкретной версии; универсальной команды принудительного обновления здесь нет.

Для первого перехода со штатной прошивки смотрите [страницу устройства OpenWrt](https://openwrt.org/toh/hwdata/d-link/d-link_dir-2150_r1). Не используйте этот sysupgrade-файл вместо требуемого factory-образа.
